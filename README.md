# DevOps Capstone Project

## Customer Accounts Microservice

A RESTful microservice for managing customer accounts, built as the culminating project for the **DevOps specialization on Coursera**.

---

## About the Project

This project implements a customer accounts microservice that exposes a REST API for performing **CRUD (Create, Read, Update, Delete)** operations on customer records.

The service is built with **Python and Flask**, with a database backend for persistent storage of customer information such as names and addresses.

The project follows industry-standard **DevOps practices**, demonstrating the complete software development lifecycle — from Agile planning and development to CI/CD, containerization, deployment, and monitoring.

---

## Key Features

- **REST API** — Create, read, update, delete, and list customer accounts
- **Python & Flask** — Lightweight framework for building the microservice
- **Database Integration** — Persistent storage for customer data
- **Agile Planning** — Sprint planning and tracking using GitHub Projects
- **CI/CD** — Automated build, testing, and deployment pipelines
- **Observability** — Logging, metrics, and tracing capabilities
- **Containerization** — Docker support for consistent and portable deployments
